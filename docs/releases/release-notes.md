# Changelog

匣流 XiaFlow — 更新日志。格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [1.0.0] - 2026-11-18

首个正式版本。

### 新增

**核心引擎**
- 基于 7-Zip 26.06 官方引擎（独立进程）的压缩 / 解压 / 校验 / 列取全流程封装
- 真实进度（`-bsp1` 引擎输出解析）、速度与剩余时间；进程级暂停（NtSuspendProcess）/ 恢复 / 取消
- 中文文件名全链路 UTF-8 支持（`-sccUTF-8` / `-scsUTF-8`）
- LZ4（.lz4 帧格式）管理流式压缩与解压
- 格式能力表诚实声明：创建（7z/zip/tar/gz/bz2/xz/wim/lz4）、修改（7z/zip/tar）、RAR 仅解压

**三大特色功能**
- 智能批量解压中心：递归扫描导入、自动识别分类（格式/加密/分卷/损坏/重复/已处理）、6 种输出模式、冲突策略、密码库匹配、逐项与全局暂停/恢复/取消、TXT/CSV 报告导出
- 压缩包内部文件管理中心：目录导航与面包屑、搜索、单文件/目录提取、文本/代码/图片安全预览（8MB 限制）、SHA-256、完整性测试、7z/zip/tar 的添加/删除/重命名
- 自动备份与压缩中心：完整/增量/差异备份、manifest 文件索引与备份链、Windows 任务计划程序调度、启动补跑、DPAPI 加密、备份自动校验、保留策略清理（依赖检查）、备份历史与统计、文件恢复中心（原位置/新位置、覆盖清单确认、冲突策略）

**任务中心**
- 压缩/解压/批量/校验/备份/恢复统一调度：队列、并行限制、暂停恢复取消重试、历史记录持久化

**系统集成**
- 右键压缩菜单（文件与文件夹）、压缩格式右键子菜单（打开/解压/批量队列/测试）、「打开方式」候选、开机启动、系统托盘与气泡通知、单实例命令行转发

**安全**
- Zip Slip 路径穿越防护、绝对路径拒绝、非法字符清洗、Windows 保留名中和、符号链接跳过
- 压缩炸弹防护（总量/单文件/文件数上限）、磁盘空间预检
- 密码库 DPAPI 加密（绝不明文、绝不写入日志）、密码强度评估
- 更新包 SHA-256 强制校验，失败绝不执行

**界面**
- 深色 / 浅色 / 跟随系统三态主题、11 个功能页面、页面过渡与拖放反馈动画
- 通知中心、备份统计仪表、历史记录

**更新**
- GitHub Releases 更新源（stable/beta 通道）、断点续传下载、跳过版本、校验通过后自动启动安装

**分发**
- Windows x64 安装版（Inno Setup 中文向导，可选右键菜单/文件关联）与便携版
